# パース共通手順

1. 設定を読む: `$cfg = & .\scripts\Get-Config.ps1`
2. 入力: ユーザが指定した収集フォルダ。未指定なら `COLLECT_DIR` 直下の最新フォルダを提示して確認する。
3. 対象ファイルは収集フォルダ内をファイル名で検索して特定する(CDIR-Cの出力構成に依存しないため)。
4. 出力先: `<PARSED_DIR>\<収集フォルダ名>\<各スキルの出力名>\`
5. `$` を含むパス(`$MFT` など)はシングルクォートで囲む。
6. 収集データは変更しない。
   - ツールの画面出力を絞り込むときは `Where-Object { $_ -match '...' }` を使う。`Select-String` などの読み取り系コマンドを `PARSED_DIR` と同じコマンドに書くと、Claude Code ではフックにブロックされる。
7. 失敗したらエラー内容を報告して停止する。
8. 完了したら出力CSVのパスだけを報告する。中身は読まない。読むときは `safe-read` スキルを使う。
